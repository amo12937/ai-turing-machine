# AI Turing Machine

日本語のチューリングマシンシミュレーター。依存パッケージとビルド工程は不要です。

## 機能

- 左右に拡張するテープと、ヘッド・現在の状態の表示
- 初回訪問時の自動再生。1秒に1ステップ
- 1ステップ進む・戻る、停止、初期化
- テープの移動アニメーションと方向表示
- 停止中のテープ・動作規則編集
- CSV インポート・エクスポート
- URL フラグメントに動作規則を埋め込んだ共有
- ブラウザ内への保存
- 二進数カウンターを初期搭載

## ローカル実行

プロジェクト直下で `python3 -m http.server 8000 --directory dist` を実行し、`http://localhost:8000` を開きます。

## 検証

Node.js 22 以上で `npm test` を実行します。

## GitHub Pages

Settings → Pages → Build and deployment → Source を GitHub Actions に設定します。
`main` への PUSH でテストを実行し、成功すると `dist` が公開されます。

## 動作規則

CSV の列順は `state,read,write,move,next` です。空欄は空記号、移動は `L`・`R`・`S` です。初期状態は `start`、ヘッド位置は 0、テープは空です。
共有URLは規則のみを保持し、開くと空のテープから開始します。

## サンプルと停止条件

停止中に、二進数の2数加算・二進列の回文判定・二進数カウンター・3状態3記号と6状態2記号のビジービーバーを読み込めます。規則とテープ、実行履歴は置き換わります。

特別な停止状態名はありません。現在の状態と記号に一致する規則がないと計算停止します。`halt` はサンプルで使う通常の状態名で、`halt` からの規則を定義すると続行できます。移動 `S` はヘッドの移動なしを意味します。

「𝕏 で共有」は、現在の規則を含むURLをXの投稿作成画面に渡します。投稿は利用者が確認して行います。

## 入力を変更できる計算サンプル

- 二進数の2数加算：例 `101+11` → `1000`。右の数を1減らし、左の数を1増やす処理を繰り返します。最後に右側の数と区切りを消去します。負でない整数に対応し、先頭のゼロは結果にも残る場合があります。
- 二進列の回文判定：例 `10101` → `accept`、`10110` → `reject`。左右の記号を照合し、照合済み位置を `X` に書き換えます。

入力欄を変更してからサンプルボタンを押してください。入力の書き込み自体も `input_…` 状態の通常の遷移規則で行うため、CSV や共有URLだけで入力準備から再現できます。加算の初期例は準備を含め70ステップ、回文の初期例は47ステップです。計算はJavaScriptの加算や文字列反転で代行せず、すべて規則表を実行します。

## 2026-10-27 サンプル更新

加算は2つのラベル付き入力欄、回文判定は二進列の入力欄から読み込めます。Enterでも読み込め、再生中は編集できません。入力準備は規則に含まれるためCSVとURLでも再現できます。

交互書き込みと111のサンプルを削除しました。

## ビジービーバーのサンプル

- 3状態・3記号：Terry・Shawn Ligocki、2007年11月の原型。119,112,334,170,342,540ステップで停止し、374,676,383個の非空記号を残します。1秒1ステップなら約37.7億年です。開始状態を変更して1ステップ延長した変種は採用していません。
- 6状態・2記号：Pavel Kropitz、2022年5月30日の機械。ユーザー指定の日本語Wikipediaの遷移表と同じです。停止までのステップ数は10↑↑15を超えます。10↑↑15は10を15段積んだ指数タワーです。

状態数は停止状態を除きます。原資料の A → start、H/Z → halt、記号 0 → 空記号と置換しています。いずれも停止が解析された機械ですが、最大性は未証明です。6状態のサンプルを最新記録とは表記しません。

テストでは原資料の遷移表、既知の途中配置、停止遷移、巻き戻し、CSVと共有URLの往復を検証します。巨大なステップ数を最後まで逐次実行するテストは行いません。通常の再生は引き続き1秒1ステップです。
